Power Analysis

Sample size and statistical power for common multi-omics study designs.

Select a study type from the left to open its calculator.

General continuous-outcome comparison, user-supplied effect size (or means/SD), suitable across omics types where a standardized effect size and variance are the natural inputs.

Used when solving for power.
Used when solving for sample size.
Standardized effect size, (mean1 − mean2) / pooled SD (≈ effect / √variance).

Two-sample comparison, equal group sizes, normal-approximation to the noncentral t-distribution (Cohen's method). Optional FDR correction follows Tarazona et al. 2020 (Nat Commun 11:3092), Eq. 3: α* = m₁α / [(m−m₁)(1−α)], with m₁ = features × expected % DE, and the entered α used as the target FDR.

Proteomics differential abundance, framed as a two-sample comparison of a continuous (e.g. log-intensity) outcome - same underlying model as the Multi-Omics tab.

Used when solving for power.
Used when solving for sample size.
Standardized effect size, (mean1 − mean2) / pooled SD.

Two-sample comparison, equal group sizes, normal-approximation to the noncentral t-distribution (Cohen's method). Adequate for typical proteomics/metabolomics-style continuous outcomes. Optional FDR correction follows Tarazona et al. 2020, Eq. 3.

RNA-seq differential expression - negative-binomial Wald-test approximation (Hart et al. 2013, Bioinformatics; as implemented in the RNASeqPower Bioconductor package).

Used when solving for power.
Used when solving for sample size.
Average count per gene per sample, at the sequencing depth planned.
Biological coefficient of variation; ~0.4 is a common bulk RNA-seq default.
Ratio between condition means, e.g. 2 = two-fold change.

Negative-binomial mean-variance model (Var = μ + CV²μ²), Wald test on log fold-change, normal approximation (delta method) - analytic, not simulation-based, matching the closed-form approach used by RNASeqPower.

Metagenomics differential abundance, reuses the same negative-binomial Wald-test approximation as Transcriptomics. Typical compositional/biological CV runs higher than RNA-seq due to sparsity and compositionality; default below is a starting point, not a validated metagenomics-specific constant.

Used when solving for power.
Used when solving for sample size.
Average normalized read count per taxon per sample.
Often higher than RNA-seq (~0.6–1.0) due to microbiome sparsity/compositionality.
Ratio between condition mean abundances.

Not independently validated for metagenomic data. This reuses the RNA-seq negative-binomial Wald approximation with no Dirichlet-Multinomial or compositional-specific correction. Treat as a rough planning estimate; for a design decision that matters, cross-check with a simulation-based tool using real pilot data.
