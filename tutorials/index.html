Tutorials

Self-contained teaching notebooks for R, Linux, and multi-omics bioinformatics — part of an ongoing R / Linux / Omics series.

Module 1: R Basics for Genomics

R fundamentals taught through a genomics lens — data types, vectors, matrices, data frames, and a single dog dataset built up throughout. Mostly base R, nothing to download. ~15–25 min, Google Colab (R runtime).

Open in Colab · View on GitHub · README

Module 2: Linux / Command Line for Bioinformatics

The shell taught through real bioinformatics file types — a toy VCF, PLINK .bim/.fam, and FASTA, covering pipes, redirection, awk/sed/grep, and shell scripting. Nothing to download. Google Colab (default runtime, %%bash cells).

Open in Colab · View on GitHub · README

Module 3: GWAS (iMAP-Dairy)

A complete genome-wide association workflow — QC, PCA, GRM, heritability, single- and multi-trait GWAS, Manhattan/QQ/Miami plots — on a small sanitized dairy-cattle subset (588 cows × 12,747 SNPs). PLINK2 + GCTA, installed from bioconda. Google Colab (default runtime, %%bash + Python cells), ~1–2 min install + <1 min run.

Open in Colab · View on GitHub · README

Module 4: WGS reads to a checked VCF

Real whole-genome reads of a Holstein calf and its two parents, taken through FastQC, fastp, BWA-MEM and bcftools to a quality-checked VCF in plain shell commands; then QA/QC of a complete 132-animal published VCF (missingness, MAF, Hardy-Weinberg, heterozygosity, filtering). Google Colab (default runtime, %%bash cells), ~9 min total.

Open in Colab · View on GitHub · README
